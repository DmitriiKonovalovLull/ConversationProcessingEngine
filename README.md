# Conversation Processing Engine

Java-сервис обработки диалогов. Входящее сообщение проходит через сохранение истории, AI-интеграцию, выбор действия и отправку ответа в канал.

Стек: Java 21, Spring Boot 3.2, PostgreSQL, Spring Data JPA и Flyway. Проект содержит интеграции и mock-реализации; готовность к эксплуатации требует отдельной проверки.

## Архитектура

Основной код находится в `src/main/java/com/aisales/`:

- `api/` — HTTP-контроллеры и DTO;
- `application/` — работа с диалогами, сообщениями и решениями;
- `domain/`, `repository/` — модели и хранение;
- `pipeline/` — этапы обработки сообщения;
- `integration/` — AI-клиенты и отправка ответов;
- `metrics/` — метрики обработки.

## Локальная проверка

Понадобятся JDK 21 и PostgreSQL. Настройки подключения задавайте локально через переменные окружения Spring: `SPRING_DATASOURCE_URL`, `SPRING_DATASOURCE_USERNAME`, `SPRING_DATASOURCE_PASSWORD`. Не используйте опубликованные значения конфигурации для собственного окружения.

В Windows:

```powershell
.\mvnw.cmd test
.\mvnw.cmd spring-boot:run
```

В этой итерации Maven-сборка и интеграционный запуск не выполнялись. Перед запуском проверьте выбранную реализацию AI-клиента и отправителя сообщений, чтобы тестовые запросы не попали в реальные каналы.

## Дальнейшая работа

Нужны интеграционные тесты pipeline с mock-адаптерами, проверка повторной доставки сообщений и сценариев ошибок, а также документированный нагрузочный тест. Подробная карта классов сохранена в [PROJECT_README.md](PROJECT_README.md), установка — в [INSTALL.md](INSTALL.md).
